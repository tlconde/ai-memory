# Memory

Memory lets you pick up where earlier sessions left off. It holds what you learned and cannot see again from here.

Before you state something from memory, search the log for it. Treat what you recall without a search as a guess.

Store only what the environment does not already show. Code, git history, docs and command output can be read again, so leave them out.

When you write a note, cite the log lines that support it. A note without evidence is a hypothesis, and this index labels it so.

Past findings were imported from an older memory. They are unverified leads that may be wrong or stale. Verify one against the current environment before you rely on it.

When memory and the current environment disagree, trust the environment. Then fix or remove the note.

Keep notes short and about one thing each. Write them when something will matter later, not to keep a record.
